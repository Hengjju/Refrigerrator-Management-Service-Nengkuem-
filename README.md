## Features

| 기능 | 설명 |
| :--- | :--- |
| 🧺 Drag & Drop 등록 | 왼쪽 식재료 목록에서 원하는 품목을 냉장고 칸으로 끌어다 놓아 등록할 수 있습니다. |
| 🍽️ 수동 품목 추가 | `+` 버튼을 통해 카테고리, 품목, 이름, 메모, 유통기한을 직접 입력하여 추가할 수 있습니다. |
| 📝 상세 정보 수정 | 등록된 식재료를 클릭하여 이름, 메모, 유통기한을 수정할 수 있습니다. |
| 🗑️ 식재료 삭제 | 상세 정보 창의 삭제 버튼 또는 냉장고 바깥 드롭을 통해 식재료를 삭제할 수 있습니다. |
| ⏳ 유통기한 표시 | 유통기한까지 남은 기간을 색상과 D-Day로 표시하여 상태를 쉽게 확인할 수 있습니다. |
| 🧅 중복 식재료 그룹 | 같은 식재료가 여러 개 있을 경우 하나의 그룹으로 묶어 깔끔하게 표시합니다. |
| 📋 전체 보기 | 냉장 칸과 냉동 칸에 들어 있는 식재료를 전체 목록으로 확인할 수 있습니다. |
| ☑️ 다중 삭제 | 전체 보기 화면에서 여러 식재료를 선택하여 한 번에 삭제할 수 있습니다. |
| ❄️ 냉장고형 UI | 실제 냉장고처럼 냉동 칸과 냉장 칸을 나누어 식재료를 직관적으로 관리할 수 있습니다. |
